How the RoV Analytics System Works

Three programs in two languages, joined by one contract. Python runs where the screenshots are. TypeScript runs where the data lives. They never import each other.

1. The three programs

Your PC runs the extractor. Your NAS runs Convex. A dashboard will come later and read Convex directly. The moving dots show which way requests travel.

Follow the highlight. Each step names who does the work.

Steps 1 to 6 need nothing but your PC. Steps 2, 7 and 8 need the NAS to be reachable.

3. How Python calls TypeScript

It never calls a TypeScript function in-process. The Convex Python client sends a function name and JSON arguments over the network. The Convex server on the NAS runs the TypeScript handler and returns JSON. Any language with a Convex client can call the same function, which is why the future dashboard needs no Python.

export const upsert = mutation({
  args: { series: v.any(), game: v.any() },
  handler: async (ctx, { series, game }) => {

  },
});

Uploading a screenshot is three calls

Ask for a URLfiles:generateUploadUrl returns a one-time upload address.
POST the bytesPlain HTTP upload to that address. Convex answers with a storage id.
Link itfiles:saveImage records series, game, kind and the storage id.

Reading goes the other way: files:imageUrl returns a signed link and Python downloads it into the series folder.

Draft statisticsConvex draftActionsderived from the JSONOne row per action makes "first pick" an indexed query.
ScreenshotsConvex file storagelocal file, a cachepurge-images deletes the cache; the app fetches again on demand.
Hero art and learned cropsPC onlynoneGarena artwork and training data, kept out of git and Convex.
One rule to remember. Recognition needs the image file on the PC. If you purged it, the app downloads it back from Convex before Recognise runs. That is the only moment a stored image comes home.

5. Which language runs where, and why

LayerLanguageRuns onWhy that language
Browser pagesHTML, CSS, JavaScriptany browser on the LANBrowsers run JavaScript, nothing else.
Extractor API and recognitionPythonyour PCOpenCV and RapidOCR are Python libraries. Local CPU, no cloud cost.
Convex functionsTypeScriptthe NAS, inside ConvexConvex only executes JavaScript or TypeScript. Deployed, not run locally.
DashboardTypeScript, Reactbrowser, later Vercel or CloudflareThe Convex React client gives live queries for free.

This is the classic three-tier split of client, API and database, with one twist: Convex plays both the API and the database, and it accepts clients written in any language. The Python program and the future TypeScript dashboard are simply two clients of the same backend.
